研究工作台

毕业论文的离线工作台：从 README、实验报告和数据台账自动生成，一页看清数据、实验进度、案例库和文献。

形式　单文件离线 HTML，双击即开构建　Python 脚本同步进度并生成页面模块　7 个
数据可视化自动化构建研究管理原生 JavaScript

工作台里是未答辩论文的实验数据，这里先只放截图，可交互版本暂不公开。

背景与问题

论文推进过程中，数据说明、实验批次、结果报告、论文稿和文献分散在几百个文件里，每次讨论都要重新翻找，也容易把“跑完了”误当成“结论成立”。

整体流程

  1. 唯一进度入口根目录 README 与决策记录
  2. 同步脚本提取进度、实验清单、论文进度，登记来源哈希
  3. 构建脚本生成数据中心、实验、案例库等页面数据
  4. 离线页面7 个模块，单文件可直接打开

我做了什么

  • 设计 7 个模块：研究总览、数据中心、实验进度与结果、论文阅读与进度、案例知识库、参考文献、版本与来源。
  • 编写同步与构建脚本：进度只从唯一入口读取并登记来源哈希，页面不另外维护一份进度，避免两处不一致。
  • 在页面上把“运行完成”“已复核”“科学结论”分开标注，运行完成不等于通过检验。
  • 数据中心逐列解释字段、单位与适用边界；案例库支持按来源、主体和时段筛选并查看近邻示例。

关键设计与取舍

页面由脚本生成，不手工维护

做法同步脚本读取唯一的进度入口，构建脚本输出页面数据。

原因与代价手工维护的看板很快会和真实进度脱节；代价是新增议题或改变实验阶段时，需要同步更新脚本里的映射。

做成单文件离线页面

做法数据内嵌在页面里，不依赖后端服务。

原因与代价组会、答疑时双击就能打开，也方便发给导师；代价是数据是某一时刻的快照，需要重新构建才能更新。
